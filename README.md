# OOP Exercise

This is my Python OOP exercise. It includes operator overloading and inheritance.

## Files

- `operator_overloading.py`: Problems 1, 2, 4, 5, 6 and 7.
- `inheritance.py`: Problems 1, 2 and 3.

## Operator overloading

I created simple classes to work with Python operators:

- `ComplexNumber`: add and subtract complex numbers.
- `Person`: compare two people by age.
- `Vector`: calculate the dot product.
- `Circle`: compare circles by radius.
- `Point`: compare points by their distance from the origin.
- `Matrix`: multiply two matrices.

The exercise does not include Problem 3 in this section.

## Inheritance

- `Vehicle`, `Car` and `Bicycle`: different `drive` methods.
- `Person`, `Student` and `Employee`: different introductions.
- `BankAccount` and `SavingsAccount`: deposits, withdrawals, transfers and interest.

## How to run

You need Python 3. Open a terminal in this folder and run:

```bash
python3 operator_overloading.py
python3 inheritance.py
```

Both files print some examples so you can see how the classes work.
